Features

Everything You Need,
Nothing You Don't

Purpose-built for Salesforce professionals. Every tool saves time and eliminates context-switching.

Lightning Command Palette

Press Shift + Space to search Objects, Records, Apex Classes, Flows, Custom Metadata, Permission Sets, and Setup Pages. Like Spotlight for Salesforce.

Record Inspector

View every field — hidden, system, audit. Export JSON, filter dynamically, clone records with one click.

Monaco Code Editor

The same engine behind VS Code. Write Apex, execute anonymous code, run tests — right in your browser.

Data Export & Import

SOQL with autocomplete, pagination, CSV/JSON export. Import with validation and field mapping.

LWC Inspector

Inspect Lightning Web Components, explore hierarchy, view reactive state, trace shadow DOM.

Debug Log Manager

Create trace flags, customize log levels with a checkbox matrix, and analyze logs with syntax highlighting and governor limit tracking.

Field API Names

Overlay API names on Lightning layouts. Copy any field's API name instantly.

Flow Scanner

Detect active Flows, Subflows, Process Builders, and Workflow Rules on any page.

Permission Wizard

Manage Permission Sets and bulk-create custom fields with guided wizards.

REST Explorer

Execute raw REST and GraphQL calls against your org directly.

API Stats

Monitor real-time API usage and governor limits at a glance.

Colored Favicons

Color-coded browser tabs for Production, Sandbox, and Developer orgs.
